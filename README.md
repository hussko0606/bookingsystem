# Booking System

A booking system built with Java and Spring Boot as a portfolio project during my System Developer studies.

## Goal
Build a complete application where users can create, view, update and cancel bookings.

## Planned features
- Create, view, update and cancel bookings
- Customer information
- Services and available times
- Validation and error handling
- MySQL database
- REST API
- Automated tests
- Simple frontend

## Tech stack
- Java 21
- Spring Boot
- Spring Web MVC
- Spring Data JPA
- MySQL
- Maven
- JUnit

## Project status
Work in progress. The project is developed step by step with focus on clean structure, testing and understanding the code.
